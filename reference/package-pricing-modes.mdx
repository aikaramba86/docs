A package is a starting point for a booking: its events, the crew each needs, a price and optional add-ons. Settings, Packages. Three ways to price one.

<Note>
Last checked: 30 October 2026, Zorlo release 2.
</Note>

## The three modes

| Mode | Set up as | On a new booking |
| --- | --- | --- |
| Fixed | One price, or labelled options such as "Weekday \$6,800" and "Weekend \$7,400" | The admin picks an option. Its price plus any add-ons becomes the suggested agreed price |
| By hours | A table of hours and prices, for example 4 hours \$1,000, 6 hours \$1,400, 8 hours \$1,700. The steps need not be even | The admin picks the hours. That price plus add-ons becomes the suggested agreed price |
| Custom | No price. Everything else as usual | The admin types the agreed price |

## What every package holds

| Part | Holds |
| --- | --- |
| Name, category, description | Shown when choosing a package on a booking |
| Active | Inactive packages are kept for old bookings but cannot be chosen for new ones |
| Prices | The options above, up to 20 |
| Events | Up to 20 events the package includes, each with an event type, hours, and the crew needed by role and level, for example Photographer Lead 1, Photographer Second 1, Videographer Lead 1 |
| Deliverables | What the package hands over after the shoot, chosen from Settings, Deliverable types, each with a quantity and whether it is complimentary |
| Add-ons | Up to 30 optional extras with a price, for example "Extra highlight film \$600". Each can be switched off |

## Rules

- **The agreed price is always editable.** The package suggests a price. The admin can type any amount, and custom packages are common.
- **The deposit is suggested from the agreed price** using the studio's deposit percentage, and can also be changed on the booking.
- **A booking copies the package.** Creating a booking from a package copies its events, crew requirements, deliverables and price onto the booking. Changing the package afterwards never alters existing bookings.
- **Changing a booking's package** shows what would be added or removed, and the admin ticks what to apply. Nothing changes silently.
- **Crew roles and levels on a package** come from Settings, Crew roles and levels. A level can be left blank to mean "anyone with that role".

## Who can edit packages

The owner, or admins when the owner has opened Packages and add-ons (Settings, Admin permissions).
